# Проверка бесплатного Cloudflare Worker

Это диагностическая функция, не готовый мониторинг. Она проверяет HTML обоих запросов, не использует платные услуги, Browser Rendering, Telegram или cron. Ответ `ready: true` требует карточек, ссылок и подтверждения поискового запроса, но не гарантирует стабильность следующих запусков. JavaScript Авито не выполняется: если сервер отдаёт оболочку без карточек, этот тест её не превратит в объявления.

## Запуск через браузер, в том числе с iPhone

1. Войдите на https://dash.cloudflare.com/ и выберите Workers & Pages (в некоторых версиях интерфейса — Compute & AI → Workers & Pages).
2. Create application → Create Worker / Start with Hello World. Назовите `avito-winx-probe`, оставьте бесплатный тариф, нажмите Deploy.
3. Откройте Edit code и замените содержимое основного файла кодом `worker.js` из этой папки. Нажмите Deploy.
4. Откройте URL вида `https://avito-winx-probe.ВАШ-ПОДДОМЕН.workers.dev/probe`. Он вернёт результаты двух поисков. Первый ответ 200 без карточек не означает успех.
5. Пришлите ссылку или JSON результата. Токен Cloudflare для этой проверки передавать не нужно.

Не обновляйте страницу многократно: каждое открытие вызывает два запроса к Авито. После диагностики удалите Worker либо закройте доступ через Cloudflare Access. Расписание здесь отсутствует; оно появится только после подтверждения доступности.

## Если уже настроен Wrangler

```bash
cd cloudflare
npx wrangler deploy
```

Для авторизации используйте штатный вход Wrangler в свой аккаунт. Не публикуйте API-токены в коде или переписке.
